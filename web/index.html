War

The card game War, played by the computer against itself: a final project for an AP Computer Science class (December 2016, tidied in March 2017). The deck is shuffled and dealt, and the program plays until one player has every card, then prints how it went. Its Java classes run unchanged in your browser.

Loading Java (the first visit downloads the runtime, which can take a little while)...

Each game is dealt from a fresh shuffle, so the number of rounds and wars changes every time.

Runs in your browser with CheerpJ (Leaning Technologies).
